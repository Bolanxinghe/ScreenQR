# 实现与验收范围

## 已明确的目标

在 Windows 电脑上，拖动取景框覆盖屏幕二维码，即可本地识别并在电脑打开网址。一般文本、Wi-Fi 和名片可查看、复制。无需第二台设备。

## 独立实现

透明取景框 → Windows 桌面区域像素 → ZXing-C++ → 内容分流与结果面板。普通网址确认后交给默认浏览器，微信内容经严格校验后交给本机微信原生图片扫码流程。没有摄像头注入、手机或模拟器依赖，不包含其它产品二进制、反编译源码或研究素材。

## 工程控制

- 原创 Python/Tk 界面；固定版本的 Pillow、ZXing-C++；PyInstaller 附带运行时生成便携版。
- 桌面像素坐标采用 DPI aware 模式，支持虚拟桌面的有符号坐标。实际多屏混合缩放仍需独立测试。
- 取景中心采用颜色键透明；截取范围避开标题、边框、底栏，不依赖隐藏整个窗口的捕获排除。其他窗口的遮挡必须由用户移开。
- 捕获与识别只有一个工作线程，不积压帧；暂停或位置变化使旧结果失效；界面只在主线程更新。
- 普通网址必须显示预览和完整地址，点击后重新检查当前画面与目标身份，去重且只打开一次；多码明确点选，不默认选首项。切换来源、位置、显示环境或其它实例变化撤销旧确认。
- 仅允许经过校验的 HTTP/HTTPS 地址交给浏览器；应用专用协议、命令、文件路径不执行。
- 图像只存内存，不上传。本机历史最近 100 条可关闭、可清空，不含截图，付款码不保存；复制写剪贴板，确认打开后浏览器会访问目标，微信收到用户框选的画面后按其自身规则处理。
- 微信配置白名单、原图不可变、严格选区和身份保护；控制器开始后共享两秒输入期限，提交后十秒只读观察。一次提交、未知不重试，多码与已知付款码输入前停止。版本或显示设置不匹配时微信停用，普通扫码可继续。
- 默认没有联网更新、性能上传或后台遥测。可显式启用的开发测试只记录公开标记的数字耗时，非正常用户模式，也不验证业务。
- F1 集中用法、支持范围、自测、版本与本机校验；环境报告不采屏、不输入、不上传。整包校验不能代替可信来源或数字签名。

## 发布边界

原创 MIT；固定依赖许可证随包附带。当前为未签名 x64 发布候选版，未发布 GitHub，云端 CI 与来源证明待实际运行。版本对应的真实验收按 EXE 哈希记录，源码检查、合成解码、真实框扫、微信初始页及业务办成分别报告。微信初始页出现不代表登录、入群或支付成功。其它电脑、显示组合及缺少有效凭据的业务继续标待验证。
