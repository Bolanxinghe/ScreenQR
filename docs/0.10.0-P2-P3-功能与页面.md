# 0.10.0-dev：P2 功能与 P3 页面整理

承接通过验收的 P1。依赖版本与许可不变，微信支持范围和默认严格门禁未放宽。没有实现实验模式、联网更新、托盘和全局热键；保留现有窗口切换及快捷键，避免增加后台生命周期和输入冲突。

## 本次实现

- 本机 JSON 原子保存最近 100 条，文件上限 2 MB，按最旧记录逐条淘汰，不截断单条内容。停止记录、重启保持、清空与存储失败处理均独立于扫码。重复画面不重复写盘。付款码不记录，无截图、遥测和联网入口。
- 常见一维条码加入既有有限、多层搜索；大图长条码补充保留全长的整行/列条带。底层库会合并上下同文条码的边界，本程序按原像素空白恢复独立实例，保留多码判断。
- 主页面加入复制、在浏览器打开、顶栏历史入口；只有多个码时显示可滚动点选列表。普通网址仍先展示目标，点击后重新核对来源、全部实例列表、目标像素和显示环境。切换目标、改变场景或移动窗口撤销旧确认。多码点选不授权微信输入，微信仍需重新框成唯一目标。
- 结果正文可滚动，历史页可看全文；历史打开从当前记录重新取原文并执行 HTTP(S) 与微信分流门禁，不使用磁盘中的任意动作字段。打开历史时暂停实时扫描，关闭后恢复。
- 取景中心不加覆盖引导；空结果时在底栏给一屏内用法，框扫后自动收起。F1 帮助包含历史隐私、条形码、多个码、微信边界和系统风险提示。主页面没有勾选、实验入口或重复原图窗口；历史页只有本机保存开关和清空入口。

## 回归与真实验收

377 项 P1 基线检查通过后开始改动。新增记录、条码、选择与浏览器边界检查；每个代码块后执行完整检查。开发中发现并修复固定库格式组合 API 不兼容、底层同文条码合并和测试构造状态缺少预览字段的问题，原失败日志保留。

最终源码、EXE、真实桌面结果及未验证项以本版 build-info.json 为准。合成图片检查不是业务通过；未实际更改系统缩放、多屏或其它电脑条件的项目仍待用户真机验证。历史的扫码正文属于用户本机数据，不能打入发行包或上传开源仓库。
