# 开源发布检查

更新：2026-10-26，0.10.1-rc1。当前是未签名发布候选，不宣称所有 Windows 或微信业务可用。尚未发布 GitHub，云端构建及来源证明尚待首次运行。历史验收保留版本、哈希与未验证项，本版结果见[发布候选验收](0.10.1-发布候选验收.md)。

只发布本ScreenQR源码目录。ScreenCameraLab和work研究目录、私人图像/聊天/账号、微信/AndroMeld闭源程序、反编译材料和私人截图模板不进入仓库。dist、build、缓存由.gitignore排除，发布包单独构建并记录哈希。

## 发布资产

- 原创 MIT、固定依赖、完整第三方声明与许可证。只公开白名单源码、公开合成样本生成器及整理后的文档，不包含工作目录、截图、研究程序、私人二维码、聊天或本机历史。
- 本机历史可停止/清空，记录不在源码包或便携包内；环境报告不采屏、不输入、不上传。没有新增网络客户端、配置下载、实验模式或全局热键。
- 微信原图、来源、实例、严格选区、多码和付款码门禁保留。控制器开始后共用两秒输入期限，提交后十秒只读观察；一次提交，未知不重试。普通扫码计算不共用此输入期限。
- F1 用法、支持范围、自测、关于；实际 EXE 校验码与本机整包校验；一键保存环境报告，无需用户 Python。
- 构建先执行源码检查，检查冻结模块与源码一致，再生成本次构建元数据及 SHA-256；GitHub 动作固定提交，云端来源证明由独立任务生成。未实际云端执行的部分不标通过。
- 业务用途矩阵与公开格式样本明确分开。格式能扫不等于微信签发凭证有效，也不证明登录、入群或支付办成。

## 由维护者决定是否公开测试发布

依据[发布前总清单](发布前总清单.md)核对已测/待测，不使用“全 Windows 通用”“所有微信二维码都能办成”或“开源所以绝对安全”等说法。当前微信只支持 4.1.15.13、单屏 3200×2000、200%。其他电脑、100%/125%/150%、混合多屏、热插拔和睡眠恢复仍待真机。

100 次/30 分钟、延迟分布与源码检查是不同证据。0.5 秒解码目标与两秒微信输入预算也不是同一个指标；没有实际微信完成时延证据时不得把预算写成业务耗时达标。缺少真实签发凭据的业务继续待验证。

首次云端构建、来源证明核对、朋友的干净 Windows 真机测试、普通用户措辞反馈仍须完成。未签名是本次明确选项，不要求购买证书；系统拦截风险如实说明，免费签名可另行申请，不自动获批。
